## 2. Доказательства инвариантов циклов

### Доказательство 1: `contains(x)` в `DynamicArray`

```java
public boolean contains(int value) {
    for (int i = 0; i < size; i++) {
        Metrics.incrementSteps();
        Metrics.incrementComparisons();
        if (data[i] == value) {
            return true;
        }
    }
    return false;
}
Формулировка инварианта (Invariant Statement):

В начале итерации i (где 0≤i≤size) искомое значение x отсутствует в подмассиве data[0 .. i - 1].

Инициализация (Initialization):

Перед первой итерацией (i=0) подмассив data[0 .. -1] пуст. Утверждение истинно.

Сохранение (Maintenance):

Предположим, что инвариант верен перед итерацией i. Во время итерации проверяется data[i] == value. Если элемент найден, цикл завершается с true. Если не найден, i увеличивается до i+1. Так как x∈
/
data[0..i−1] и x

=data[i], то x∈
/
data[0..i], и инвариант сохраняется для i+1.

Завершение (Termination):

Цикл останавливается, если найден элемент (возвращая true), либо когда i=size. При i=size инвариант гарантирует, что x∈
/
data[0..size−1]. Метод корректно возвращает false.

Вывод (Conclusion):

Инвариант цикла доказывает, что contains(x) корректно определяет наличие элемента без ложных срабатываний.

Доказательство 2: bubbleDown(int index) в MinHeap
Java
private void bubbleDown(int index) {
    while (hasLeftChild(index)) {
        int smallestChildIndex = getLeftChildIndex(index);
        if (hasRightChild(index) && rightChild(index) < leftChild(index)) {
            smallestChildIndex = getRightChildIndex(index);
        }
        Metrics.incrementComparisons();
        if (heap[index] <= heap[smallestChildIndex]) {
            break;
        }
        swap(index, smallestChildIndex);
        index = smallestChildIndex;
    }
}
Формулировка инварианта (Invariant Statement):

В начале каждой итерации цикла while для всех узлов k

=index выполняется свойство минимальной кучи: heap[k]≤heap[дети]. Единственное потенциальное нарушение свойства находится в узле index.

Инициализация (Initialization):

Перед стартом цикла последний элемент был перемещен в корень (index = 0). Все остальные поддеревья соблюдают свойство кучи. Инвариант выполняется.

Сохранение (Maintenance):

Если heap[index] больше наименьшего ребенка, обмен (swap) восстанавливает порядок кучи между текущим узлом и его детьми. Потенциальное нарушение перемещается на уровень ниже — в smallestChildIndex, и переменная index обновляется. Инвариант сохраняется для следующего шага.

Завершение (Termination):

Цикл завершается, когда heap[index] <= heap[smallestChildIndex] или когда узел index становится листом (нет детей). В обоих случаях нарушения свойства кучи в дереве отсутствуют.

Вывод (Conclusion):

Инвариант доказывает, что bubbleDown полностью восстанавливает структуру минимальной двоичной кучи.

3. Результаты и обсуждение бенчмарка
Локальность данных и аппаратные особенности
Локальность кэша процессора (DynamicArray):

DynamicArray хранит элементы в непрерывном блоке памяти. При доступе к элементу процессор загружает в кэш целую кэш-линию (64 байта, до 16 чисел int). Это обеспечивает высокий процент попаданий в кэш (cache hits) и высокую скорость работы.

Переход по указателям и расходы на GC (MyLinkedList):

Каждый узел MyLinkedList выделяется в памяти отдельно. Переход по ссылкам (pointer chasing) приводит к частым промахам кэша (cache misses). Каждый узел также содержит служебный заголовок объекта (12–16 байт) и указатели, что увеличивает расход памяти.

Рекомендации по выбору структур:

DynamicArray: лучше всего подходит для прямого доступа по индексу, добавления в конец и работы с большим объемом данных при ограниченной памяти.

MyLinkedList: подходит, когда операции вставки и удаления происходят строго на границах (голова/хвост) без доступа по индексу.

MinHeap: незаменим для приоритетных очередей и задач, где требуется постоянный доступ к минимальному элементу.
